tekst:
  pl: |
    ### Pytanie tak/nie: czasownik na początku

    Zamieniasz miejscami podmiot i czasownik. Żadnego słówka typu *czy* nie potrzeba:

    - *U heeft batterijen.* → **Heeft u batterijen?**
    - *Jij woont hier.* → **Woon je hier?**
    - *Er is een groot pak.* → **Is er een groot pak?**

    Przed *jij* i *je* znika *-t*: **woon je?**, **ben jij?**, **heb jij?** (zob. *Czas teraźniejszy*). Przy *u* i *hij* zostaje: **woont u?**

    ### Pytanie ze słowem pytającym

    Słowo pytające, potem czasownik, potem podmiot: **Waar woon je?** **Wat drink je?**

    | słowo | po polsku | przykład |
    |---|---|---|
    | wat | co | **Wat is dit?** |
    | wie | kto | **Wie is dat?** |
    | waar | gdzie | **Waar is de apotheek?** |
    | waar … vandaan | skąd | **Waar kom je vandaan?** |
    | wanneer | kiedy | **Wanneer kan ik komen?** |
    | hoe | jak | **Hoe kom ik bij het station?** |
    | hoe laat | o której | **Hoe laat komt de bus?** |
    | hoeveel | ile | **Hoeveel kost het?** |
    | waarom | dlaczego | **Waarom kom je later?** |
    | welk / welke | który | **Welke kleur wilt u?** |

    *Welk* stoi przed słowem z *het* w liczbie pojedynczej (**welk spoor?**), *welke* przed wszystkimi innymi (**welke kleur?**, **welke dagen?**).

    ### Dwa czasowniki

    Drugi czasownik i tu idzie na koniec: **Wilt u de kaart zien?** **Wat heb jij gedaan?**
  nl: |
    ### Ja/nee-vraag: het werkwoord vooraan

    Je draait onderwerp en werkwoord om. Een extra vraagwoordje is niet nodig:

    - *U heeft batterijen.* → **Heeft u batterijen?**
    - *Jij woont hier.* → **Woon je hier?**
    - *Er is een groot pak.* → **Is er een groot pak?**

    Vóór *jij* en *je* valt de *-t* weg: **woon je?**, **ben jij?**, **heb jij?** (zie *De tegenwoordige tijd*). Bij *u* en *hij* blijft hij staan: **woont u?**

    ### Vraag met een vraagwoord

    Eerst het vraagwoord, dan het werkwoord, dan het onderwerp: **Waar woon je?** **Wat drink je?**

    | vraagwoord | vraagt naar | voorbeeld |
    |---|---|---|
    | wat | een ding | **Wat is dit?** |
    | wie | een persoon | **Wie is dat?** |
    | waar | een plaats | **Waar is de apotheek?** |
    | waar … vandaan | herkomst | **Waar kom je vandaan?** |
    | wanneer | een moment | **Wanneer kan ik komen?** |
    | hoe | de manier | **Hoe kom ik bij het station?** |
    | hoe laat | de tijd | **Hoe laat komt de bus?** |
    | hoeveel | een aantal | **Hoeveel kost het?** |
    | waarom | de reden | **Waarom kom je later?** |
    | welk / welke | een keuze | **Welke kleur wilt u?** |

    *Welk* staat voor een het-woord in het enkelvoud (**welk spoor?**), *welke* voor alle andere (**welke kleur?**, **welke dagen?**).

    ### Twee werkwoorden

    Het tweede werkwoord gaat ook hier naar het eind: **Wilt u de kaart zien?** **Wat heb jij gedaan?**
anders:
  pl: |
    Po polsku pytanie często różni się od zdania tylko intonacją albo słowem *czy*: *Pan ma baterie?*, *Czy pan ma baterie?* Po niderlandzku sama intonacja nie wystarczy, a słowa *czy* nie ma: pytanie robisz szykiem, czasownikiem na początku.

    Po polsku po słowie pytającym szyk jest wolny (*Gdzie ty mieszkasz?*, *Gdzie mieszkasz?*). Po niderlandzku czasownik stoi zawsze zaraz po nim, a podmiotu nie pomijasz: **Waar woon je?**
